# Author decisions before public GitHub publication

1. Correct manuscript section 2.2 to distinguish the source/development missingness threshold from final Gate 0. Preserve the 453-building final results, including the 31 buildings above 20% overall missingness.
2. Approve a Supplementary Data S17 inventory addendum (existing CSV lists one checkpoint; the release's separately measured external-artifact inventory lists all three).
3. Confirm rights to publish the manuscript draft and data-derived small prediction/validation fixtures, provide the required BDG2 attribution and license notices, and choose a license for original code. No license is assumed here.
4. Decide where the exact frozen source checkpoints/full prediction archive will be hosted if full replay should be publicly downloadable. Neither is bundled; all six excluded input hashes were calculated from actual local files.
5. Review path-redacted historical reports, GAPS.md, source_map_final.csv and the automated privacy scan scope.
6. Choose/create a GitHub repository. This project had no connected repository, so no commit was made. Public push requires the researcher's explicit approval.

This checklist records publication decisions; it does not authorize changing final results or retraining to improve the paper.
