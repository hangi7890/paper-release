# Supplementary Final Package

## Primary documents

- `Supplementary_Materials.md` and `Supplementary_Materials.docx`: English Supplementary Methods, compact Tables S1-S10, Figures S1-S7, and data availability notes.
- `Supplementary_Master_Structure.md`: frozen Supplementary numbering and main-text first-citation locations.
- `Manuscript_Supplementary_Crossrefs.md`: exact v2 section anchors, proposed citation sentences, and v2-to-v3 numbering changes.
- `Supplementary_Formulas_and_Code.md`: equations and the relation to the model-free reference implementation.
- `DATA_DICTIONARY.md`: Data S1-S17 schemas and statistical units.
- `SOURCE_TRACE.md`: source paths, sizes, hashes, fields, transformations, commands, and known unavailable measurements.
- `artifact_manifest.csv`: size, SHA-256, and role for every packaged artifact.
- `Supplementary_Package_v1.zip` and `PACKAGE_SHA256.txt`: publication handoff package and its integrity record.

## Directories

- `tables`: compact editable CSV versions of Tables S1-S10.
- `figures`: each Figure S1-S7 in 600 dpi PNG, SVG, and PDF.
- `data`: full filterable Data S1-S17 CSV files.
- `code`: package-build and reference-formula code. It does not train or run inference.
- `qa`: data validation, document rendering, and visual review records.
- `reference`: preserved copy of the supplied handoff reference. It is excluded from the publication ZIP.

The package does not modify the integrated manuscript, main Figure/Table package, final predictions, checkpoints, or existing reports.
