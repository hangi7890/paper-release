# BDG2 v5 개발 분석 규칙 고정본

## 성격과 적용 범위

이 문서는 기존 C0 개발 예측을 v5에서 재분석할 때 사용할 판정 규칙을 고정한다. 기존 v3 결과가 이미 존재하므로 이 문서는 전향적 사전등록이 아니다. 개발용 탐색 결과를 본 뒤 최종 시험 규칙을 다시 바꾸는 일을 막기 위한 분석 사양이다.

- 대상: 동결된 Source 20개 건물과 개발 12개 건물.
- 예산: `0, 1, 3, 7, 14, 28`일.
- 고정 시험: 건물당 28개 일별 창, 창당 24개 정답.
- 시드: `20260924, 20260925, 20260926`.
- 수치 동률 허용오차: `EPS = 1e-12`. 이는 실질효과 임계값이 아니라 부동소수점 동일성 판정용이다.
- 최종 시험 사이트 전력은 읽지 않는다.

## 적응량과 학습 창

| 적응일 | 타깃 정답 시간 | 슬라이딩 24→24 학습 창 |
| ---: | ---: | ---: |
| 0 | 0 | 0 |
| 1 | 24 | 1 |
| 3 | 72 | 49 |
| 7 | 168 | 145 |
| 14 | 336 | 313 |
| 28 | 672 | 649 |

적응일이 `d>0`일 때 창 수는 `24d-23`이다. 0일은 Target 정답을 사용하는 학습이 없는 Source-only 조건이다.

## 오차 변화와 두 성공 질문

같은 건물·시드·시험 정답에 대해 다음을 계산한다.

- `ΔMAE_source(d) = MAE_adapt(d) - MAE_source`.
- `ΔRMSE_source(d) = RMSE_adapt(d) - RMSE_source`.
- `relative ΔMAE_source(%) = 100 × ΔMAE_source / MAE_source`.
- `relative ΔRMSE_source(%) = 100 × ΔRMSE_source / RMSE_source`.
- `gap_MAE_baseline(d) = MAE_adapt(d) - MAE_baseline`.
- `gap_RMSE_baseline(d) = RMSE_adapt(d) - RMSE_baseline`.

음수는 적응 모델의 오차가 더 작다는 뜻이다. 다음 질문은 별도로 보고한다.

1. **A 질문:** Source-only보다 개선됐는가?
2. **B 질문:** `previous_day` 및 `weekly_same_hour` 기준선보다도 오차가 작은가?

A의 성공이 B의 성공을 뜻하지 않는다. 두 기준선은 각각 보고하고, 둘 중 하나보다 나쁜 경우와 둘 모두보다 나쁜 경우도 구분한다.

## F1~F4 실패 정의

비제로 적응 예산 `d∈{1,3,7,14,28}`에 대해:

- **F1:** `ΔMAE_source(d) > EPS`.
- **F2:** `ΔRMSE_source(d) > EPS`.
- **F3-PD:** `MAE_adapt(d) - MAE_previous_day > EPS`.
- **F3-W:** `MAE_adapt(d) - MAE_weekly_same_hour > EPS`.
- **F3-any:** F3-PD 또는 F3-W.
- **F3-both:** F3-PD와 F3-W가 모두 참.
- **F4:** 같은 건물·예산의 세 시드 중 `ΔMAE_source < -EPS`인 시드와 `ΔMAE_source > EPS`인 시드가 모두 존재.

F1~F3은 건물×예산×시드 사건으로 집계한다. F4는 건물×예산 사건으로 집계한다. 시드 평균 판정은 별도 열로 두고 개별 시드 사건을 대체하지 않는다. 정확한 동률은 개선과 악화 어느 쪽에도 넣지 않는다.

`ΔMAE_source < -EPS`이면서 `ΔRMSE_source > EPS`인 경우를 **MAE 개선·RMSE 악화 불일치**로 별도 기록한다.

## 적응 곡선 분류

각 건물의 세 시드 평균 MAE를 예산 순서 `0→1→3→7→14→28`로 배열하고 연속 차이를 계산한다.

- **decrease/nonincreasing:** 모든 연속 차이가 `≤EPS`이고 하나 이상이 `<-EPS`.
- **increase/nondecreasing:** 모든 연속 차이가 `≥-EPS`이고 하나 이상이 `>EPS`.
- **flat:** 모든 연속 차이의 절댓값이 `≤EPS`.
- **nonmonotonic:** 증가 단계와 감소 단계가 모두 존재.

별도로 0일 대비 28일의 순변화를 개선·악화·동률로 기록한다. 비단조 곡선이더라도 순개선일 수 있으므로 두 판정을 합치지 않는다.

## 대표 실패 사례 선정

성능이 유리한 사례를 임의 선택하지 않도록 다음 순서를 고정한다.

1. **반복 F1:** 시드 평균 F1이 발생한 비제로 예산 수가 가장 많은 건물. 동률이면 최대 시드 평균 `ΔMAE_source`, 그다음 `building_id` 오름차순.
2. **F4:** F4 사건 중 시드별 `ΔMAE_source` 범위가 가장 큰 건물×예산. 동률이면 `building_id`, 예산 오름차순.
3. **MAE/RMSE 불일치:** 해당 사건이 있으면 `ΔRMSE_source`가 가장 큰 사건. 없으면 `없음`으로 보고하고 대체 사례를 고르지 않는다.

선정 사례의 실제값과 예측값은 이미 저장된 개발 prediction CSV에서만 사용한다. 시험 기간이나 시드를 바꾸지 않는다.

## 건물 특성의 정보 시점

- Source 규모 통계는 Source 학습 구간만 사용한다.
- Target 시험 정답은 특성 계산에 사용하지 않는다.
- 0일 조건의 적응 데이터 기반 장기 통계는 `NA`이다. 첫 예측 직전 24시간 입력 이력으로 계산한 별도 context 특성은 사용할 수 있으나 적응 28일 통계로 간주하지 않는다.
- `d>0` 조건은 해당 예산에서 허용된 초기 24시간 입력 context와 적응 종료 시각까지의 관측만 사용한다. 사용 시작·종료·시간 수를 행마다 기록한다.
- 일간 반복성은 최소 두 날짜의 대응값이 있을 때만, 주간 반복성은 최소 168시간 lag 쌍이 있을 때만 계산한다. 정의되지 않으면 대체 수치를 넣지 않는다.
- 평균, 표준편차, 변동계수, 0값 비율, 일간·주간 반복성, Source와의 규모 차이, site와 용도만 탐색한다. 시험 결과를 이용한 변수 추가나 임계값 조정은 하지 않는다.
- 연관성은 탐색적 상관 또는 층화 기술통계로 보고하며 인과관계로 해석하지 않는다.

## 대표 집계 원칙

- 건물 결과는 세 시드를 모두 공개한다.
- 건물 요약은 시드 평균과 표준편차를 함께 쓴다.
- 사이트 요약은 해당 사이트 건물을 동일 가중치로 집계한다.
- 전체 요약은 건물을 동일 가중치로 집계하며 관측 시간 수로 대형 건물에 추가 가중하지 않는다.
- 모든 예산을 보고하며 가장 좋은 예산만 골라 결론을 만들지 않는다.
